# Photo Judge — Operator Walkthrough (video outline)

A script outline for a full demonstration video.

- **Audience:** club operators who run competition nights (light technical comfort assumed).
- **Length:** full deep-dive, ~18–22 minutes.
- **Order:** follows the real workflow — setup → getting photos in → monitors/network →
  presenting & scoring (basic, then the guided modes) → after the night.
- Timings are guides; the chapter markers double as YouTube timestamps.

> **Production tips:** rehearse on the demo data so categories/photos look real; have the
> phones / second laptop pre-connected to avoid dead air during the entries and judge
> segments; add the chapter titles below as YouTube timestamps so operators can jump
> straight to "Judge scoring." Section 6 (the guided modes) is the part operators most need
> — keep it whole rather than trim.

---

## 0. Cold open & intro — *0:45*
- One line on what it is: a **fully offline, single-file Windows app** that presents a club's
  competition photos across **two monitors** and records the scores — no install, no
  internet, runs from a USB stick.
- Show launching `photo-judge.exe` → the **Operator Console** opens; point out the **nav
  rail** on the right (every page lives there) and the version in the corner.
- Promise: "By the end you'll be able to run a whole night start to finish."

## 1. Create & set up a session — *2:00*
- **➕ New session** → pick the date, type a **description** (e.g. "April competition — judged
  by Jane Smith"); explain a session = one night.
- Open **🗂️ Session Management**: the **Active / Inactive** category panes — add,
  activate/deactivate (deactivate keeps photos), reorder; note the order drives every menu
  and the score sheet.
- In the **Scoring** card set the **win threshold** (e.g. 11 of 15) — preview that this powers
  winner badges and stats later.
- Mention new sessions inherit the last one's setup.

## 2. Add the photos — *2:30*
- **🖼️ Upload / Reorder**: drag in JPG/PNG → auto-sorted **Landscape / Portrait**; drag
  thumbnails to set viewing order.
- **🔀 Randomize this category / whole session** for unbiased order; **Spread photographers
  when randomizing** (Settings) so one person's photos aren't adjacent.
- Type **photographer** names; show the optional **metadata import** (artist/title from the
  file).

## 3. Collect last-minute entries from members *(optional)* — *2:00*
- The use case: members upload from their **phones** as they arrive.
- Settings → **Enable member entries** (limits, Wi-Fi); set a screen's Type to **Entry QR**;
  show the competitor phone flow (join Wi-Fi, scan, name, upload) and the **🛂 Review** queue
  (approve → lands in the right category).
- *(Demo prep: have a phone on the same network ready.)*

## 4. Monitors & a second device — *2:00*
- **➕ Create Screen** for each display; **⧉ Open window**, drag to the monitor, press **F**
  for fullscreen.
- **Rotate a monitor for portrait** photos (physical turn + Windows Display orientation) —
  quick mention.
- **Run from a second laptop/phone over the network**: Settings → LAN, the nav's **QR code**,
  and the **Private network + firewall** caveat (only on a trusted network). This sets up the
  scorekeeper/judge devices used later.

## 5. The simple way: present + score by hand — *2:30*
- **Free-form console:** Load a category onto a screen, then **◀ Prev / Next ▶**,
  **Black/Reveal**, **★ Make live**. Step at the judges' pace; start black.
- **🏆 Scoring page (classic scorekeeper):** follow a screen, move at your own pace or lock to
  the operator, type a score + **Enter**; **📋 Physical prints** table for printed entries.
- This is the baseline — "great if you're not using the built-in scoring features."

## 6. ⭐ The guided, mistake-proof way (the centerpiece) — *6:00*
Frame it: "When you're scoring a night, this ties presenting and scoring together so nothing
misfires."

- **Settings → pick a mode:** Guided presentation, Score Keeper, or Judge scoring (note Score
  Keeper & Judge are mutually exclusive).
- **Presentation card** (Session Management): which screen shows each orientation, show-first,
  when-it-ends.
- **6a. Guided presentation** — the **Start / Pause / End** bar; until Start the monitors are
  **black** and screen controls are **locked**; Start → the **panel** appears; one **Prev /
  Next** steps the photo across orientations and categories automatically.
- **6b. Score Keeper mode** — the **inline score box** on the console (winner flag); then flip
  on **"Use a separate scorekeeper screen"** so a **second operator** scores on the Scoring
  page while you drive (show both screens side by side).
- **6c. Judge scoring** — per-session **Judge mode rules** (combine, judges needed, range,
  alternate, anonymize); set a **Judge QR** screen; judges **join from phones** (show the
  joined count gating Start); the **judge board** (each score, combined, N/needed), **defer to
  alternate** / auto-defer, and **Rescore**. *(Demo prep: 2–3 phones.)*
- **6d. Lifecycle niceties** — **Pause** to reconfigure mid-show; the **end-of-photos prompt**;
  **End locks the scores**; **✓ judged** marker on the dropdown; **Restart** (warn: erases
  scores) to redo a night.

## 7. After the night — *2:30*
- **⤓ Score sheet** PDF (photos + prints + scores).
- **📊 Statistics**: Entries / **Winners** (driven by the threshold) / Compare; time-frame
  filters.
- **⇄ Import / Export**: move whole sessions between computers as **.pjs / .pjss** (new IDs on
  import, no clashes).
- **🗄 Archive** a past session: permanent record + reclaims disk (deletes the image files,
  read-only) — warn it's irreversible; export first if you want the pictures.

## 8. Wrap-up — *0:45*
- Recap the two ways to run a night (free-form vs guided modes) and when to use each.
- Point to the built-in **📖 How To** page and where to get help.
