Photo Judge — Settings

Scoring

Lock the scorekeeper to the operator's photo
The Scoring page follows whatever photo the operator is presenting; the scorekeeper can't flip ahead on their own.

Presenting

Only one live screen at a time
Revealing a screen automatically blacks out all the others, so two monitors never show at once.
Spread photographers when randomizing
When you randomize photo order on the Upload / Reorder page, try to keep the same photographer's photos from landing next to each other (when the mix allows).

Title card logo

Upload one or more logos and pick which appears above the category name on the judges' title cards. A transparent PNG looks best on the black card. Uploaded logos are kept here until you delete them.

PDF header

Heading shown at the top of the score-sheet and archive PDFs — e.g. your club's name. Leave blank to use "Photo Judge".
0 / 90 characters (kept short so it fits two lines)

Network

Allow control from other devices on the network (LAN)
Shows the LAN address and QR code so a phone or second laptop can connect. Takes effect after restarting the app.

Read metadata from uploaded photos

When a photo has the matching info embedded, fill it in automatically on upload.
Photographer (EXIF/PNG artist or author)
Fill the photographer box from the photo's metadata.
Title
Use the photo's embedded title as its on-screen name (filename).

Member entries

Let competitors submit their own photos from the Entry-QR screen. Limits count every photo by a photographer's name for the session (including ones an operator added), so the same name can't go over by using another device. Leave a box as "Unlimited" to allow any number.
Enable member entries
Master switch. When off, screens can't be set to Entry QR and the entry form is closed.
Require approval before adding entries
On: submissions wait in the Review queue for you to approve. Off: each photo is added straight into the session.
Total entries per competitor
The most photos one competitor can submit across all categories.
Entries per category (per competitor)
The most a competitor can submit into any single category.

Wi-Fi for entries

Shown on the Entry-QR screen so competitors can join the network before scanning. Leave blank to use the host computer's current Wi-Fi (auto-detected). The password appears on that screen, so only fill this in for a network you're happy to share.
