============================================================
 PHOTO JUDGE  —  User Guide
============================================================

Photo Judge shows competition photos to judges on one or more
monitors, while you (the operator) line up the next photo
privately on the laptop. You drive everything from a control
page in your web browser; the judges only ever see clean photos
on black, with a title card announcing each category.

Nothing to install. Everything lives next to the program file.


------------------------------------------------------------
 1. STARTING THE APP
------------------------------------------------------------

1. Double-click  photo-judge.exe
2. The FIRST time on a new computer, Windows may warn
   "Windows protected your PC / unknown publisher".
   Click  More info  ->  Run anyway.  (One time only.)
3. A small command window opens AND your web browser opens to
   the control page automatically.
     * Leave the command window open while you use the app
       (you can minimize it). Closing it stops the app.
     * If the browser didn't open, or you closed the tab, just
       go to:   http://127.0.0.1
       (If you changed the port - see below - add it, e.g.
        http://127.0.0.1:8753 .)

On first run the app creates these next to itself:
     photos\                  - where all photos are stored
     logo\                    - optional logo for the title cards
     archives\                - records of archived sessions (see #9)
     categories.txt           - seed for the first session's categories
     photo-judge.properties   - settings you can change (see below)

CHANGING THE PORT  (optional)
   By default the app listens on port 80, so the control page is at
   http://127.0.0.1 . If something else on the computer already uses
   port 80, open  photo-judge.properties  in Notepad and either:
     * set a different number, e.g.   port=8753   (then use
       http://127.0.0.1:8753 ), or
     * set   autoPort=true   to let the app pick any free port for
       you (the command window prints the address it chose).
   Save the file and restart the app for changes to take effect.

CONTROLLING IT FROM ANOTHER DEVICE ON THE NETWORK  (optional)
   You can run the show from a second laptop, a phone, or a tablet
   that is on the SAME network (same Wi-Fi or the same wired router)
   as the computer running Photo Judge. The judges' monitors stay
   plugged into the main computer; you just get a second control page.

   This is on by default. To turn it off (so the app only answers on
   the computer itself), open  photo-judge.properties  and set
   lanAccess=false , then restart - the address bar and QR button
   disappear.

   WHERE TO FIND THE ADDRESS
     At the top of the operator console there is a bar:
        "Control from another device on this network: http://192.168.x.x"
     * On the other device, open a web browser and type that address.
     * Or click "Show QR code" and scan it with a phone/tablet camera
       to open the control page instantly. (If the computer has more
       than one network address, the QR window lets you pick which.)
     If the bar does NOT appear, the computer has no usable network
     connection (it's offline, or only has a loopback address).

   ONE-TIME WINDOWS SETUP (so other devices are allowed to connect)
     Windows blocks incoming connections until you allow the app:
     1. The first time you start Photo Judge, Windows may pop up
        "Allow photo-judge to communicate on these networks".
        Tick  Private networks  and click  Allow access.
     2. If you didn't see that prompt, or it still won't connect:
        - Make sure the network is set to PRIVATE, not Public:
          Settings -> Network & Internet -> (your Wi-Fi/Ethernet)
          -> set "Network profile type" to  Private.
        - Allow the app through the firewall:
          Windows Security -> Firewall & network protection ->
          "Allow an app through firewall" -> Change settings ->
          "Allow another app..." -> Browse to  photo-judge.exe  ->
          Add, and make sure its  Private  box is ticked.

   GOOD TO KNOW
     * Both devices must be on the same network. Guest Wi-Fi and many
       hotel / conference networks block device-to-device traffic
       ("client isolation"), so use your own router or hotspot.
     * The address (192.168.x.x) can change if the computer reconnects
       to the network; if a saved link stops working, re-check the bar
       on the console for the current address.
     * This is for control only - it does not add judges' monitors.
       Open output windows still belong to the main computer.
     * The pages are touch-friendly on a phone or tablet. On the
       Upload / Reorder page, drag a photo by its "⠿ drag" grip to
       reorder it (on a computer you can also just drag the photo).
       "Open window" only appears on the main computer, since judges'
       windows can't be opened from a phone.

READING PHOTO METADATA  (optional)
   If your photographers embed their name and the photo's title in the
   image file, the app can read them automatically on upload. Open
   photo-judge.properties and set  importMetadata=true , then restart.
   From then on, an uploaded photo's embedded photographer (artist /
   author) fills the photographer box, and its embedded title is used
   as the photo's on-screen name. Missing values change nothing, and
   you can still edit the photographer by hand. (Off by default - see
   section 4 for how it appears on the Upload page.)


------------------------------------------------------------
 2. THE BIG PICTURE
------------------------------------------------------------

SESSION    - One competition night, labeled by date. Everything
             is organized under a session. You pick or create a
             session before doing anything else.

CATEGORY   - A judging category (e.g. Wildlife, Macro). Each
             session has its own list, set in "Manage categories"
             (see section 7). Each category has a Landscape group
             and a Portrait group of photos.

SCREEN     - A display you present on (e.g. "Landscape monitor").
             You create named screens, then open a window for
             each and put it on the right monitor.

So the flow is:  pick a Session  ->  add photos to its
categories  ->  open your Screens  ->  present.

GETTING AROUND - Every page has a menu down the RIGHT edge that
             takes you between pages (Console, Upload / Reorder,
             Manage categories, Scoring, Getting Started). It starts
             as a slim strip of icons; click the menu button at its
             top to expand it and see the page names (and the address
             / QR code for connecting another device). On a phone the
             menu is hidden behind a small menu button in the top-right
             corner. When this guide says to "open" or "click" one of
             those pages, that's where you find it.


------------------------------------------------------------
 3. TYPICAL RUN  —  STEP BY STEP
------------------------------------------------------------

A) CREATE / PICK A SESSION  (do this first!)
   On the control page, click "➕ New session" to open a small
   box: choose the date and (optionally) type a DESCRIPTION - a
   short note to tell sessions apart, e.g. "April competition -
   judged by Jane". Click "Create". Or pick an existing session
   from the Session dropdown; "Edit session" changes its date and
   description. The description shows under the toolbar, on the
   Archived Sessions page, and on the printed score sheet.

B) SET UP CATEGORIES  (optional - see section 7)
   Click "Manage categories" to activate/reorder/add this
   session's categories. A new session already inherits the last
   session's setup, so you can usually skip this.

C) ADD PHOTOS  (can be done ahead of time)
   Click "Upload / Reorder", choose the session, category, and
   Landscape or Portrait, then drag your photos in. Drag the
   thumbnails to set the order judges will see them in.

D) CREATE YOUR SCREENS
   Click "Create Screen" and name it (e.g. "Landscape monitor").
   Repeat for each display. Screens are remembered for next time.

E) OPEN EACH SCREEN'S WINDOW
   On a screen's row, click "Open window". Move the new window
   to the correct monitor, then click it (or press F) to go
   fullscreen. It starts black.

F) PRESENT
   On a screen's row: choose a Category + Landscape/Portrait,
   click "Load". The monitor shows the category TITLE CARD.
   Click "Next" to reveal the first photo, "Next"/"Prev" to
   move through them. Black out or switch categories anytime.


------------------------------------------------------------
 4. ADDING & ORGANIZING PHOTOS  ("Upload / Reorder" page)
------------------------------------------------------------

* Pick Session and Category at the top. The page shows the
  photos already in that category, split into a Landscape
  section and a Portrait section.
* If you haven't made a session yet, the page shows short
  instructions instead of the upload area — create a session
  (see section 3) and it switches to the uploader automatically.
* UPLOAD: drag image files onto the drop area, or click it to
  browse. Only JPG and PNG files are accepted. You do NOT pick
  Landscape or Portrait — each photo is filed automatically by
  its shape (taller than wide = Portrait, otherwise Landscape).
  A JPG that was rotated in-camera is filed by how it actually
  looks (its rotation metadata is honored). Folders are created
  as needed.
* PHOTOGRAPHER: type a name in the box under a photo to record
  who took it. It's saved automatically and is pre-filled into
  the score-sheet PDF.
* FROM METADATA (optional): if you turn on  importMetadata=true  in
  photo-judge.properties, each uploaded photo is checked for an
  embedded photographer (artist/author) and title. A photographer is
  filled into the box for you, and a title is used as the photo's
  on-screen name (instead of the file's name). Anything missing is
  left as-is, and you can still edit the photographer by hand. (Off by
  default; see section 1.)
* REORDER: drag a thumbnail to a new spot within its section.
  The number badge shows the display order. Saved instantly.
  (Photos can't be dragged between Landscape and Portrait —
  orientation follows the photo's shape.)
* REMOVE: click the small x on a thumbnail to remove a photo.
* If two photos have the same filename, the new one is renamed
  (e.g. "sunset (2).jpg") so nothing is overwritten.
* Anything that isn't a JPG or PNG is ignored.


------------------------------------------------------------
 5. SCREENS
------------------------------------------------------------

* CREATE SCREEN  - makes a named screen and remembers it. It
  does NOT open a window by itself.
* Open window  - launches (or relaunches) that screen's display
  window. Use this if a window was closed or blocked.
* Trash icon   - deletes the screen (its window goes black).

Screens are saved between launches. When you reopen the app,
your screens are listed again BUT with no category selected, on
purpose, so a photo can never appear before you choose one.


------------------------------------------------------------
 6. PRESENTING  (control page buttons)
------------------------------------------------------------

Per screen row:
   Category / Orientation menus + Load
                 - load that group; the monitor shows the title
                   card (start of the run). Loading always starts
                   at the beginning.
   Prev / Next   - step backward / forward through the photos.
                   (Title card -> photo 1 -> photo 2 -> ... -> black)
   Black / Reveal- hide the screen (black) or bring it back.
   Make live     - show THIS screen and black out all the others
                   in one click (handy when alternating monitors).
   Trash icon    - delete the screen.

Top of page:
   Black all     - instantly black every screen.
   Close App     - stops the program when you're done (see #11).

The monitor not in use simply stays black on its own - there is
nothing extra to switch off.


------------------------------------------------------------
 7. CATEGORIES  (editing the list)
------------------------------------------------------------

Categories are managed PER SESSION, right in the app - open
"Manage categories" from the menu on the right.

* Pick a session at the top, then you'll see two lists:
    INACTIVE (left)  - categories not used this session
    ACTIVE   (right) - categories the judges will see, in order
* Move a category between the lists with "Activate ->" and
  "<- Deactivate".
* Reorder ACTIVE: click a category, then use the Up / Down
  buttons. This order is what you see in the menus AND on the
  score sheet, and the names are exactly what show on title
  cards - so check spelling.
* Add a new category with the box at the top (it lands in
  ACTIVE).
* Delete removes a category from this session - but only if it
  has no photos. If it has photos, Deactivate it instead (that
  keeps the photos).

NOTE: categories are per session, so changes here only affect
THIS session. A brand-new session starts with a copy of your
most recent session's categories, so your setup carries forward.
(The first ever session is seeded from  categories.txt .)


------------------------------------------------------------
 8. SCORING  ("Scoring" page)
------------------------------------------------------------

A scorekeeper can record a score for each photo while the
operator runs the show. Open "Scoring" from the menu on the
right. To keep score on a SEPARATE device while someone else
presents, open the app's address on that device instead (see
the menu's address / QR code, or section 1).

* FOLLOW A SCREEN: pick a screen at the top. The page shows
  the photos from whatever that screen currently has loaded
  (session / category / orientation).
* FLIP INDEPENDENTLY: use Prev / Next (or the left/right arrow
  keys) to move through the photos yourself - this does NOT
  change what the judges see. You can score ahead of, or behind,
  whatever the operator is presenting.
* OPERATOR INDICATOR: a panel shows which photo the operator is
  currently showing on that screen. When you're looking at the
  same photo, it turns green ("You're viewing the operator's
  current photo"). "Jump to operator's photo" snaps you to it.
* ENTER A SCORE: type a score in the box and press Enter. It's
  saved for that photo. Clear the box and press Enter to remove
  it.
* Scores show up as a green badge on the Upload / Reorder page
  and are pre-filled into the Score column of the score-sheet
  PDF (section 4 / the "Score sheet" button).

PHYSICAL PRINTS (entries with no photo file)
   Some nights you also judge actual printed photos that were never
   uploaded. Switch to the "📋 Physical prints" button at the top of
   the Scoring page to record those.
     * Pick the Session and Category at the top.
     * A small table appears with columns: Print title, Photographer,
       and Score. Just type them in - there's no image to show.
     * A fresh empty row appears automatically as soon as you start
       filling the last one, so you can keep going down the list.
     * Press Tab to move across the fields, and Enter to drop to the
       next row. Each entry saves on its own as you go.
     * The "x" at the end of a row removes that entry.
   Physical prints belong to the session you picked, so they're kept
   with it - they appear in the score-sheet PDF and, if you archive the
   session, in the archived record too.


------------------------------------------------------------
 9. ARCHIVING SESSIONS  (saving records + freeing space)
------------------------------------------------------------

When a competition night is finished and you no longer need the
actual photo files, you can ARCHIVE the session. This saves a
permanent record of the session - the photo titles, photographers,
scores, categories, orientations, the session date, and the date you
archived it - to a file, and then DELETES the photo image files to
free up disk space.

HOW TO ARCHIVE
   1. On the console, pick the session in the Session menu.
   2. An  "🗄 Archive Session"  button appears next to it - but ONLY
      for sessions whose date is in the past. (Today's or future
      sessions can't be archived; finish the night first.)
   3. Click it and confirm. The warning is important:
        * the photo image files are PERMANENTLY DELETED (this is not
          the recoverable "Delete" - the pictures are gone),
        * the session becomes read-only and leaves the console,
        * it cannot be undone.

VIEWING ARCHIVED SESSIONS
   Open  "Archived Sessions"  from the menu. Every archived session
   is listed with its date, the date it was archived, its categories,
   and how many photos it had.
     * SEARCH by any combination of: date range, session ID,
       photographer name, or photo title. (Searching a photographer
       or title expands the matching entries and highlights the hits;
       this covers physical prints too.)
     * "Show details" lists that session's photos - and any physical
       prints - with their title, photographer and score. Click any
       column heading to sort the list by it (click again to reverse).
     * "⤓ PDF" downloads a printable report of the session; "⤓ JSON"
       saves the raw record (handy for a spreadsheet or your own files).

GOOD TO KNOW
   * Archives are stored next to the program in an  archives\  folder,
     one  <id>.json  file per session.
   * Session ID numbers are never reused, so an archived session's
     number won't be handed to a future session.
   * Archiving only removes that session's CURRENT photos. If you want
     to keep the pictures themselves, copy them out of  photos\
     before archiving.


------------------------------------------------------------
 IMPORT / EXPORT - MOVING SESSIONS BETWEEN COMPUTERS
------------------------------------------------------------

You can carry whole sessions - their photos and everything else -
from one computer to another. Click  "⇄ Import / Export"  on the
console to open the wizard. It uses two file types, which are just
zip files with a Photo Judge extension:
     .pjs   = one session
     .pjss  = several sessions
Both contain everything a session needs (the photos, titles,
photographers, scores, physical prints, and - for archived nights -
the archive record), so a single file is all you have to copy.

EXPORTING
   1. On the "Export" tab you'll see a list of every session, live
      AND archived. Narrow it with the filters (active/archived,
      photographer, photo title, date range) and click a column to
      sort. Long lists are paged.
   2. Click  "Add ->"  on each session you want to send; they collect
      in the "Selected for export" box. (Or use a row's "⤓ .pjs" to
      export just that one immediately.)
   3. Click  "Export".  One session downloads as a  .pjs  file, several
      as a  .pjss.  Copy that file to a USB stick, email, etc.

IMPORTING
   1. On the "Import" tab, choose (or drag in) one or more .pjs/.pjss
      files. A table lists the sessions inside each one.
   2. Tick which sessions to "Import" (all are ticked by default). If
      you want one of them to become the selected session on the
      console afterward, tick its "Make active" box (only one allowed).
   3. Click  "Import".  Each imported session is given a NEW ID number
      so it can't clash with sessions already on this computer; the
      table then shows the new ID next to the old one.

GOOD TO KNOW
   * Importing never overwrites an existing session - you always get a
     fresh copy with a new ID.
   * The export list shows up to 50 sessions per page; change that with
     "exportPageSize" in photo-judge.properties if you like.


------------------------------------------------------------
 10. SETTINGS  ("Settings" page)
------------------------------------------------------------

Open "Settings" from the menu on the right to set app-wide options.
Each one saves as soon as you change it.

SCORING
   * Lock the scorekeeper to the operator's photo - the Scoring page
     follows whatever the operator is presenting and the scorekeeper
     can't flip ahead on their own (the lock toggle there is forced on).

PRESENTING
   * Only one live screen at a time - revealing a screen automatically
     blacks out all the others, so two monitors never show at once.

TITLE CARD LOGO
   To show a club logo above the category name on the judges' title
   cards, click "Upload logo" and pick image file(s). They're kept in
   a little gallery; click one to make it the Active logo (click it
   again to use none), or the "x" to delete it. A see-through
   (transparent) PNG looks best on the black card. Logos stay until
   you delete them.

PDF HEADER
   The heading at the top of the score-sheet and archive PDFs - put
   your club's name here, for example. Leave it blank to use
   "Photo Judge". It's limited to a length that fits two lines.

NETWORK
   * Allow control from other devices (LAN) - see section 1. This is
     also a switch here, but a "lanAccess=false" in
     photo-judge.properties wins, and a change takes effect after you
     restart the app.

READING PHOTO METADATA
   * Two switches - one for the photographer, one for the title - that
     fill those in from an uploaded photo's embedded metadata (see
     section 4). These only work when importMetadata=true in
     photo-judge.properties; a "false" there greys them out.


------------------------------------------------------------
 11. STOPPING THE APP
------------------------------------------------------------

Click "Close App" on the control page (recommended), or close
the small command window that opened at startup. Either one
fully stops the program so it isn't left running in the
background. Closing just the browser tab does NOT stop it.


------------------------------------------------------------
 12. GOOD TO KNOW
------------------------------------------------------------

* Loading a category shows the TITLE CARD first - press Next to
  reveal the first photo. (This is the deliberate "announce,
  then reveal" moment.)
* Deleted sessions and photos are not gone for good - they are
  moved into  photos\_deleted\  and can be recovered there.
* For best speed during an event, copy the whole folder onto the
  laptop's hard drive rather than running it from a USB stick.


------------------------------------------------------------
 13. TROUBLESHOOTING
------------------------------------------------------------

A window didn't open / was blocked
   Allow pop-ups for this site in your browser, then click
   "Open window" on the screen's row.

I loaded a category but the judges' screen is black
   Press "Next" - loading shows the title card first. If it is
   still black after Next, that group has no photos yet.

The display window isn't truly fullscreen
   Click anywhere on that window, or press the F key.

My logo isn't showing
   Open the Settings page (section 10), upload a logo, and click it so
   it's marked Active.

The app won't start (security warning)
   More info -> Run anyway. It is an unrecognized program only
   because it isn't code-signed; it is safe and self-contained.

Nothing happens / can't reach the page
   Make sure the command window is still open, and visit
   http://127.0.0.1 in your browser (or http://127.0.0.1:PORT if
   you set a custom "port" in photo-judge.properties).

"could not start ... port" in the command window
   Another program is using the port. Open photo-judge.properties,
   change "port" to a free number (e.g. 8753) or set autoPort=true,
   save, and restart.

Another device on the network can't open the page
   * Quick check: in a browser ON THE HOST computer, open the LAN
     address shown on the bar (e.g. http://192.168.1.5 ). If even that
     fails, the issue is the app/Windows, not the other device:
       - make sure  lanAccess=true  in photo-judge.properties (the
         default) and restart; if the address bar is missing entirely,
         it's off or the computer has no network connection.
   * If the host can open it but the other device can't:
       - check both devices are on the SAME network (not guest Wi-Fi),
       - type the address exactly as shown, including the port if one
         is shown (e.g. http://192.168.1.5:8753 ),
       - allow Photo Judge through Windows Firewall and set the network
         to Private - see "CONTROLLING IT FROM ANOTHER DEVICE" in
         section 1.


------------------------------------------------------------
 14. MOVING THE APP TO ANOTHER COMPUTER
------------------------------------------------------------

The app runs from any folder and rebuilds anything missing.

To start fresh elsewhere: copy just  photo-judge.exe.

To bring your existing content, copy the exe AND keep these in
the same folder with it:
     photos\          (all sessions, photos, AND each session's
                       category setup - the main data)
     archives\        (records of any archived sessions)
     logo\            (your logos)
     screens.json     (your saved screens)
     settings.json    (your Settings-page choices)
     photo-judge.properties  (only if you changed the port; the
                              new computer makes its own otherwise)

(categories.txt only seeds a brand-new first session, so you
don't need to copy it once you have sessions.)

Requirements on the other computer:
   * 64-bit Windows 10/11 (the laptops you use are fine)
   * Microsoft Edge (already on Windows) - nothing to install
   * Copy to a normal, writable folder (not a locked USB)
